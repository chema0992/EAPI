# EAPI: WebAPI in Entry

블록 코딩은 흔히 다음과 같은 한계를 가진다고 여겨졌습니다.

1. 복잡한 작업에는 부적합하다.
2. 주로 입문자와 교육용으로 사용된다.
3. 고성능 작품을 만들기 어렵다.

하지만 **[EAPI](https://eapi-web.pages.dev/)는 그 경계를 넓히는 것을 목표로 합니다.**

EAPI는 WebGL, WebAssembly(WASM) 등의 기술을 Entry에서 사용할 수 있도록 하며,

여러 Web API를 Entry 블록으로 직접 매핑하여 보다 높은 수준의 작품 제작을 가능하게 합니다.

> **주의:** 이 프로젝트의 소스코드는 일반적인 독립 실행형 JavaScript 파일이 아니라,
> Tampermonkey 등의 사용자 스크립트 환경에서 실행할 수 있도록 작성되었습니다.

---

## 💻 서론

EAPI는 **Entry에서 사용할 수 있는 기능의 범위를 확장하기 위해 추진된 오픈소스 프로젝트**입니다.

EAPI가 이뤄낸 업적은 다음과 같습니다.

### 1. 오픈소스

모든 주요 소스코드를 GitHub에 공개하여
사용자가 직접 코드를 확인하고 사용할 수 있도록 했습니다.

### 2. 사용자 스크립트를 통한 자동 주입

기존의 일부 비공식 블록은 개발자 도구 콘솔에
직접 코드를 입력해야 하는 방식으로 사용되었습니다.

EAPI는 Tampermonkey 등의 사용자 스크립트 환경을 이용하여
Entry 접속 시 필요한 기능을 자동으로 주입할 수 있도록 구성했습니다.

### 3. 모듈화 구조

EAPI는 기능별로 모듈을 분리하여,
필요한 API만 선택적으로 설치할 수 있도록 구성했습니다.

### 4. Web API 1:1 매핑

EAPI는 단순한 편의 블록만 제공하는 것을 목표로 하지 않습니다.

WebGL, WebAssembly 등 브라우저가 제공하는 저수준 기능을
가능한 한 원래 API의 구조에 가깝게 Entry 블록으로 제공합니다.

그 결과 강력한 기능을 사용할 수 있지만,
동시에 일반적인 Entry 블록보다 높은 학습 난이도를 가질 수 있습니다.

## 📁 설치 방법

설치 단계는 아래와 같습니다.

1. src 폴더 안에 들어갑니다.
2. 적용하고 싶은 API 블록들을 선택해 다운로드, 혹은 전체 복사합니다. (core.user.js는 필수입니다.)

적용 방법입니다.

1. TamperMonkey를 [설치](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)합니다.
2. 설정에서 권한 중 유저 스크립트 토글을 허용으로 바꿉니다.
3. TamperMonkey를 클릭하고 새 스크립트 추가를 누른 후, 에디터 창에서 .user.js 파일을 드래그 합니다. (복사 했었으면 전체 선택 후 붙여넣기 하면 끝)
4. 뭐가 막 뜰텐데 '재설치' 버튼을 눌러줍니다.
5. 새로고침 후 설치된 유저 스크립트 목록으로 들어가면 적용이 되어 있습니다.

## ⚠️ 주의사항

현재 개발 중인 프로젝트이므로 버그나 예상하지 못한 오류가 발생할 수 있습니다.

브라우저 환경에 따라 정상적으로 동작하지 않을 가능성이 있습니다.

### 작품 편집 화면의 새로고침 주의

현재 Entry의 프로젝트 로딩 과정에서 비공식 블록이
정상적으로 복원되지 않을 수 있습니다.

따라서 **작품 편집 화면에서는 가급적 새로고침하지 않는 것을 권장합니다.**

> 작품 상세 페이지에서의 새로고침은 정상적으로 동작합니다.
